# Axiom

A little play. A sharper mind.

[Play Axiom](https://trying-ai.github.io/axiom-play/) · [Browse all 18 games](https://trying-ai.github.io/axiom-play/#/games)

A free browser prototype with eighteen logic, memory and number games. New additions: **Nonogram, Skyscrapers, Lights Out, Knight Trail and Codebreaker**. Select the **New** filter in the game library to find them.

Each game has three difficulty levels, instructions and hints. Games load on demand; no download or account is required to play. Optional email accounts use Firebase Authentication. Progress stays in your browser and does not sync across devices.

This repository contains only the GitHub Pages frontend. The Rust multiplayer service is separate and is not deployed on this site.
